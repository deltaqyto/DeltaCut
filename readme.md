## Description
DeltaCut is a non-linear video editing program. The aim is to support transcript - based editing of video, 
with a secondary goal of supporting a wide range of elements and editing capabilities.

DeltaCut is built in python 3.11, using PyQT6.

Current work is directed to improving the UI and implementing core usability functionality.


### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/deltaqyto/DeltaCut.git
   ```
2. Install requirements (and python 3.11+)
   ```sh
   pip install -r requirements.txt
   ```
3. Run 'main.py'
